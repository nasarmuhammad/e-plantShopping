# Paradise Nursery Shopping Application

Welcome to Paradise Nursery — Where Green Meets Serenity!

Paradise Nursery is a responsive React shopping cart application
for an online houseplant store.

## Project Overview

Customers can browse a collection of houseplants, view plant
images and prices, add products to a shopping cart, and manage
their purchases before checkout.

## Features

- Landing page with nursery background image
- Company description and Get Started button
- Five plant categories with six plant listings each
- Product thumbnails, descriptions, names, and prices
- Add to Cart buttons that disable after selection
- Shopping cart powered by Redux Toolkit
- Dynamic shopping cart icon and item count
- Increase and decrease product quantities
- Remove individual plants from the cart
- Automatic item subtotals and overall cart total
- Continue Shopping navigation
- Checkout button displaying Coming Soon
- Navigation between Home, Plants, and Cart

## Technology Stack

- React 18
- JavaScript and JSX
- Redux Toolkit
- React Redux
- Vite
- CSS3
- GitHub Pages

## Installation

Clone the repository:

git clone https://github.com/nasarmuhammad/e-plantShopping.git

Change into the project directory:

cd e-plantShopping

Install dependencies:

npm ci

Run the development server:

npm run dev

Create a production build:

npm run build

## Project Structure

src/App.jsx - Landing page and navigation
src/App.css - Landing page styling
src/AboutUs.jsx - Company information
src/ProductList.jsx - Plant catalog and Add to Cart
src/CartSlice.jsx - Redux shopping cart state management
src/CartItem.jsx - Shopping cart interface
src/store.js - Redux store configuration
